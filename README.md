# -Face-Tracker-v9

This repository contains OBS face-tracking plugins and educational tools.

## Contents

- **OBS Face Tracker Plugin** - Face tracking plugin for OBS Studio (in `data/` and `obs-plugins/`)
- **USDT Flasher Tool** - Educational cryptocurrency transaction simulator (see [USDT_FLASHER_README.md](USDT_FLASHER_README.md))

## USDT Flasher Tool

⚠️ **Educational Tool Only** - For learning about cryptocurrency transactions

A Python-based educational tool that simulates USDT (Tether) cryptocurrency transactions for learning purposes. This tool does NOT create real transactions or interact with actual blockchain networks.

### Quick Start

```bash
python3 usdt_flasher.py
```

For detailed documentation, see [USDT_FLASHER_README.md](USDT_FLASHER_README.md)

### Important Notice

This tool is for **EDUCATIONAL PURPOSES ONLY**. It does not create real cryptocurrency transactions and should never be used for fraudulent purposes.
